# 5025251032_Todo-App

Nama : Nagita Aliya Sanopa

NRP : 5025251032

### Description
A simple and responsive Todo App that allows users to manage their daily tasks. Users can view their todo list, edit their tasks, delete tasks, mark tasks as completed using checkboxes, and add new todos.
This app is divided to 2 sides, the left side used to show the todo lists and the right side used to add new todos and edit the existing todos.
